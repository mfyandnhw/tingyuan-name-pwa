# 庭远姓名 PWA 0.1.6 · 极简解读版

本版移除《人格》《相克》《特殊格局》三份文档的自动解读展示，仅在排盘下方显示简短的跨格重复/近义特质和数理原文中的格位专属信息。天格不参与重复统计。

特别补充：数理16出现在人格或变格时显示对应原文限定信息，其他格出现16不会触发此条。其他格位限定文字匹配来自81数理OCR，待人工核验。

数理全文仍可点击格位查看原始图片。

# 庭远姓名 PWA 0.1.0

这是基于你提供的 `庭远姓名 0.4.0 APK`、JADX 导出工程及 `0.5.1` 修改工程整理出的手机桌面网页应用（PWA）首版。

## 当前包含
- 二至四字姓名排盘，自动识别常见复姓，也可手动选择姓氏字数
- 原版笔画数据、姓氏笔画、异体字及手动笔画修正
- 天格、人格、地格、变格、外格、总格六格计算
- 原版 1—81 数理吉凶与 125 组三才规则
- 点击六格查看原版数理全文图片
- 重复特质统计：至少在两个不同格子出现才显示；两次与三次及以上分组
- 本机历史记录
- 1—81 数理库
- PWA 桌面安装入口及 Service Worker 缓存

## 特质数据范围
当前 `numerology-traits.json` 只使用已有标签的 50 个数理。尚未提取标签的 31 个数理不参与统计，不做推测性补齐。重复特质按标签精确匹配；相近词不擅自合并。

## 重要说明
- 姓名与历史记录保存在当前浏览器的 localStorage 中。
- 这是 PWA，必须部署到 HTTPS 网站后，才能在手机上“添加到主屏幕/安装”。直接双击本地 `index.html` 不能完整启用 PWA。
- PWA 通过静态文件托管，无需数据库或服务器端 API。
- 首次加载需要联网；已缓存的页面与已访问过的数理图片可在网络不稳定时使用。由于用户选择“可以联网使用”，本版没有承诺完整离线功能。
- 这是首个 PWA 版本，已移植核心排盘、数理查询、特质统计和本机记录；Android 原版的“自动格局搜索/姓名推荐”等复杂筛选尚未移植到本版，后续可以继续补齐。
- 姓名学数理属于传统民俗分析体系，仅供文化研究与娱乐参考。

## 部署方法（GitHub Pages）
1. 登录 GitHub，创建一个新的 Public repository，例如 `tingyuan-name-pwa`。
2. 将本文件夹内的所有文件和文件夹上传到仓库根目录（不要只上传 ZIP）。
3. 进入仓库 Settings → Pages。
4. 在 Build and deployment 中选择 Deploy from a branch。
5. Branch 选择 `main`，目录选择 `/ (root)`，保存。
6. 等待 GitHub Pages 部署完成，得到 HTTPS 地址。
7. 在 Android Chrome 打开网址 → 浏览器菜单 → 添加到主屏幕 / 安装应用。
8. 在 iPhone Safari 打开网址 → 分享 → 添加到主屏幕。

## 本地预览
在项目根目录运行：
`python -m http.server 8000`
然后在电脑浏览器打开 `http://localhost:8000`。
本地预览可测试界面，但不能代替 HTTPS 部署后的手机安装测试。


## 后续自行修改时，主要编辑这些文件
- `app.js`：姓名计算、六格显示、重复特质统计、历史记录与交互逻辑。
- `styles.css`：手机界面颜色、字体、间距和卡片样式。
- `index.html`：页面结构、栏目名称和按钮。
- `assets/numerology-traits.json`：数理特质标签及证据。
- `assets/rules.json`：81条男女数理吉凶与三才规则。
- `assets/interpretations.json`：数理图片索引；原文图片在 `assets/numerology/`。
- `sw.js`：PWA 缓存版本。每次发布新版本时，把文件顶部 `VERSION` 字符串改成新值（例如 `tingyuan-pwa-v0.1.1`），浏览器就会更新缓存。

## 版本范围
本版优先交付“快速打开 + 核心排盘 + 数理全文 + 重复特质 + 本机记录”。Android 原版中的复杂“格局筛选/候选姓名搜索”和“冠夫姓合婚排盘”尚未移植，后续可以在这个可修改项目上继续开发。


## 0.1.2 更新

## 0.1.3 文档规则新增
- 从用户上传的《人格》《相克》《特殊格局》提取了结构化规则，保留原文以供追溯。
- 排盘后增加：人格五行与阴阳文字、特殊数理命中、五行关系、年龄段说明与原文折叠面板。
- 天格**不参与重复特质统计和吉凶统计**，但在“人克天”等结构关系中仍可能作为参与值。
- 不将文档中“99%领导、90/100%准确、一定不幸福、不到50岁”等说法作为客观概率或预测输出。
- 无完整判定条件的术语，不自动生成结论。
- 奇数阳偶数阴、五行控制关系属于通行约定，标注为补充规则，非原文显式给出的算法。


## 0.1.4 综合命理解读
- 结果页增加逐格溯源的六段解读：跨格近义特质、人格专属、格位专属、各格数理、五行与三才、年龄阶段。
- 对照已有数理标签与《人格》文档，并使用**明示的保守近义组**比对。仅跨至少两格才认定重复，同一格只记一次，天格完全排除重复计数。
- 专属触发：地格9、人格10；地格和总格相关数字另有来源范围提示。人格阴阳只对人格起效。
- 医学、寿命、婚姻、领导概率等传统断语不可作事实预测；原文缺乏完整算法的部分不补造。
- 仍有31个数理没有人工核对的特质标签，不能视为完整语义检索。


## 0.1.5 新增：81 数理 OCR 综合解读
- 纳入 81 个数理、99 张图片对应的 OCR 文字底稿；所有 31 个先前标签缺失的数理亦有底稿可查看。
- 抽取 OCR 中明确的“在人格与变格时”等格位限定描述，只有所在格位吻合时展示。
- 对 OCR 含义描述进行限定词库的近义候选初筛，只有两个及以上不同格位命中才显示；天格不计入统计。
- OCR 未逐条校对，显示为“候选”，不可当作已人工确认的事实；原有 50 数理手工标签仍保留。
- 未取得完整判定公式的通天克、连地克等规则不自动编造。
